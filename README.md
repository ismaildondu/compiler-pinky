# Pinky — A Toy Programming Language and Compiler in Python

> Official website: [https://pinky-lang.org/](https://pinky-lang.org/)

**Pinky** is a small programming language and compiler in Python.  
It was developed as part of a self study on compiler construction and programming language design following the course of **Gustavo Pezzi** (Compilers, Interpreters & Formal Languages
).

## Motivation
Compilers and programming languages are an essential part of computer science. Most developers use programming languages every day but only a few have a deep understanding of how they actually work. My motivation was to have a solid understanding about compiler theory and programming language design so that I can have a different perspective on how softwares operate.
